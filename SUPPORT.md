# Support

Yaya's Space is a personal fork looked after on a best-effort basis. There is
no support contract and no promised response time.

- **Bugs and ideas:** open an issue at
  <https://github.com/YahyaElghobashy/yayas-space-mac/issues/new/choose> with
  the version from Settings, About, your macOS version and clear steps.
- **Security:** see [SECURITY.md](SECURITY.md).
- **Docs:** [README](README.md), [Privacy](docs/PRIVACY.md),
  [Permissions](docs/PERMISSIONS.md), [Troubleshooting](docs/TROUBLESHOOTING.md),
  [Contributing](CONTRIBUTING.md).

For the upstream project this fork is based on, see
<https://github.com/vorssaint/vorssaint-utils>; please do not report Yaya's
Space issues there.
